# Taller de nivelación PI a PII

Repositorio con la solución del taller de nivelación de Programación I a Programación II
de la Institución Universitaria Antonio José Camacho (UNIAJC).

## Contenido

- **[teoria.md](teoria.md)** — Parte teórica: qué es Markdown, preguntas de Git y de programación en Java.
- **Calculadora.java** — Calculadora básica (suma, resta, multiplicación y división).
- **ContadorVocalesConsonantes.java** — Cuenta las vocales y consonantes de una palabra.
- **InvertirCadena.java** — Invierte una cadena de texto ingresada por el usuario.

## Cómo compilar y ejecutar los ejercicios

Necesitas tener instalado el JDK de Java. Desde la terminal, en la carpeta del proyecto:

```bash
# Compilar
javac Calculadora.java
javac ContadorVocalesConsonantes.java
javac InvertirCadena.java

# Ejecutar (ejemplo)
java Calculadora
java ContadorVocalesConsonantes
java InvertirCadena
```
